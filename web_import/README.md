# Original game content

This directory contains the original 1998/1999 Tímaflakkarinn content,
including PNG/WAV masters in Git LFS, plus reviewed GML corrections and
authored calibration data.

Independent public game releases and redistribution or reuse of the content
require written permission except for the collaboration permissions in the
license. The team will evaluate a more permissive content license at the
rebuilt game's v1; no automatic change is promised.

PNG/WAV media masters are preserved. Derived media (scaled, transcoded,
chroma-keyed) are regenerated by `tools/pipeline/`. GML corrections and
calibrations are reviewed, traceable changes to the authored game content.
